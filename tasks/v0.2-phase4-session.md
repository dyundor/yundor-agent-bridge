# Yundor Agent Bridge v0.2 Phase 4

目标：

增加 OpenCode Session 管理能力。

让 Bridge 可以在不同任务之间保持连续上下文。

---

## 修改范围

允许修改：

- session_manager.py（新增）
- main.py
- config.yaml

禁止修改：

- opencode_client.py
- git_manager.py
- report_parser.py
- project_reader.py
- guard.py
- market-intelligence 项目

---

# 一、新增 session_manager.py

实现：

## 1. get_saved_session(config, project)

功能：

读取指定项目保存的 session_id。

输入：

config

project name

返回：

session_id

如果不存在：

返回 None

---

## 2. save_session(config_path, project, session_id)

功能：

执行成功后保存 session_id 到 config.yaml。

要求：

不要破坏其他配置。

---

## 3. clear_session(config_path, project)

功能：

清除失效 session。

---

# 二、修改 main.py

当前流程：

创建 session
发送任务

改为：

启动

↓

读取 config.yaml

↓

读取项目

↓

检查 session_id

如果存在：

继续使用旧 session

如果不存在：

创建新 session

↓

保存 session_id

↓

发送任务

---

# 三、Session 有效性检查

如果旧 session 不可用：

自动：

1. 删除旧 session_id

2. 创建新 session

3. 保存新的 session_id

不要让程序崩溃。

---

# 四、config.yaml

增加项目 session 配置。

示例：

projects:

bridge:

    path: /Users/yundor/yundor-agent-bridge

    session_id: null

---
