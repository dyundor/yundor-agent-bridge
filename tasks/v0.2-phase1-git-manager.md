### get_commit_hash(path)

功能：
获取当前 git commit hash。

命令：

git -C path rev-parse HEAD


返回：
commit hash


---

### get_diff_summary(path)

功能：
获取当前工作区修改摘要。

命令：

git -C path diff --stat


返回：
文件变化统计。


---

### get_diff_between(path,before,after)

功能：

比较两个 commit 之间变化。


命令：

git -C path diff before..after --stat
