## 功能要求

### 1. check_path_security(path)

检查目标路径是否安全。

禁止访问：

- ~/.ssh
- ~/.aws
- ~/.gnupg
- ~/Library/Keychains

如果路径属于禁止目录：

返回：

{
"allowed": false,
"reason": "restricted directory"
}

否则：

返回：

{
"allowed": true,
"reason": ""
}

---

### 2. validate_project_path(path)

验证项目路径。

检查：

1. 路径是否存在
2. 是否为目录
3. 是否通过安全检查

成功：

返回 True

失败：

返回明确错误。

---

### 3. is_git_project(path)

检查是否为 git 项目。

如果：

.git 存在

返回：

True

否则：

False
