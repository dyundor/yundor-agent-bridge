# Yundor Agent Bridge v0.2 Phase 2

目标：

增加执行报告解析能力。

只修改：

- report_parser.py

不要修改：

- main.py
- opencode_client.py
- config.yaml
- git_manager.py
- project_reader.py


## 当前问题

OpenCode 返回的是 DeepSeek 文本。

需要把文本转换成结构化数据。


## 实现要求


增加函数：

parse_report(text)


输入：

DeepSeek 输出文本


输出：

dict


格式：

{
  "modified_files": [],
  "functions_added": [],
  "tests": [],
  "next_step": ""
}


## 解析规则


支持解析：

### Modified Files:

例如：

Modified Files:
- git_manager.py


转换：

[
"git_manager.py"
]


---

### Functions Added:

例如：

Functions Added:
- get_commit_hash()
- get_diff_summary()


转换：

[
"get_commit_hash",
"get_diff_summary"
]


---

### Test Result:

提取测试结果。


---

### Next Step:

提取下一步建议。


## 容错

如果 DeepSeek 输出格式变化：

不要报错。

返回空列表或空字符串。

parse_report()
